# Booki

Aplicativo para gerenciar uma biblioteca pessoal. O usuário poderá registrar livros, definir o status de leitura, dar notas, editar e excluir obras cadastradas, consultar preço dos livros de interesse, ter acesso a recomendações com base no seu histórico de leitura.
